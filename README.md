# Add an industrial furnace to Minecraft !

### Combine Create and an industrial furnace to quickly automate your baking.

 

<span style="color: #e03e2d;">To see how the furnace is used and how it is made, please watch the videos or go directly to Minecraft and use Ponder (press z on the desired block).</span>

 

## <span style="color: #3598db;"><strong><span style="text-decoration: underline;">Features :</span></strong></span>

*   Full compatibility with JEI ;
*   Contains Ponder scenes ;
*   En/Fr ;
*   Compatible with Create 6.0  and 5.0;

## __**Adding a Recipes with a datapack:**__

<span style="color: #95a5a6;">Adding a recipes for the industrial furnace.</span>

```json
{
  "type": "cif:cif",
  "group": "cif_processing",
  "input": {
    "item": "cif:diamond_alloy_block"
  },
  "output": {
    "item": "cif:alloynium_block",
    "count": 1
  },
  "cookingtime": 1000
}
```
